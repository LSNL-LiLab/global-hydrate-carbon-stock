# Global Hydrate Carbon Stock from BSR-Constrained Machine Learning

Code and data for estimating global marine gas hydrate carbon stock using a
physics-constrained machine-learning framework.

## Overview

This repository implements a complete pipeline that:

1. Computes the theoretical base of the gas hydrate stability zone (BGHS)
   from methane hydrate phase equilibrium.
2. Trains XGBoost classifiers on global bottom-simulating reflector (BSR)
   observations to predict BSR occurrence probability.
3. Applies a shallow-water physical constraint to suppress thermodynamically
   impossible predictions.
4. Trains an XGBoost regressor to predict the BSR residual (observed BSR depth
   minus theoretical BGHS) and converts it to absolute BSR burial depth.
5. Estimates global hydrate carbon stock under three parameter scenarios using
   the volumetric method.

The central idea is "physics sets the baseline, machine learning learns the
residual": the phase-equilibrium model provides a first-order physical
constraint, and the ML models capture systematic deviations that the physical
model cannot resolve at global scale.

## Requirements

- Python 3.12 or newer
- See `requirements.txt` for the full dependency list

Install dependencies:

```bash
pip install -r requirements.txt
```

**NumPy version note:** SciPy 1.15 officially supports NumPy `<2.5.0`. The
`requirements.txt` pins `numpy<2.5.0` to suppress a compatibility warning. The
code also runs with NumPy 2.5.1, but a warning will be printed.

## Data

### BSR observations

- `Global BSR actual observation dataset.txt`
  Tab-separated file with columns `X`, `Y`, `BSR`.
  `X` and `Y` are longitude and latitude in WGS84; `BSR` is the observed BSR
  burial depth in metres below seafloor.
- `BSR_negative_points.txt`
  Tab-separated pseudo-absence points with columns `X`, `Y`.

### Environmental rasters

The `Global feature dataset/` folder contains 13 GeoTIFFs at 0.25 degree
resolution (EPSG:4326). They were compiled from the following public sources:

| File | Source |
|------|--------|
| `global_water_depth.tif` | GEBCO 2026 |
| `global_bottom_temp.tif` | WOA23 |
| `global_bottom_salinity.tif` | WOA23 |
| `global_geothermal_gradient.tif` | IHFC GHFDB + Lucazeau heat-flow grid |
| `globa_sediment_thickness.tif` | GlobSed v3 |
| `crustal_age_0.25deg.tif` | EarthByte 2020 |
| `tectonic_environment_0.25deg.tif` | PB2002 + Slab 2.0 |
| `dist_to_ridge_0.25deg.tif` | PB2002 (Euclidean distance) |
| `dist_to_subduction_0.25deg.tif` | Slab 2.0 (Euclidean distance) |
| `global_slope.tif` | Derived from GEBCO bathymetry |
| `Ocean_stratigraphic_age.tif` | Ocean stratigraphic age grid |
| `global_BGHS_thickness_0.25deg.tif` | Generated by `1.compute_bghs.py` |
| `global_BGHS_thickness_clipped_800m.tif` | Generated by `1.compute_bghs.py` |

The two BGHS rasters are produced by `1.compute_bghs.py`. They are also
included in this repository so that downstream scripts can be run without
recomputing them.

## Pipeline

Run the scripts in numerical order from the repository root. Because the file
names contain dots, wrap them in quotes on the command line.

| Step | Script | Description |
|------|--------|-------------|
| 1 | `1.compute_bghs.py` | Compute theoretical BGHS thickness from pressure, temperature, salinity, and geothermal gradient |
| 2 | `2.plot_latitude_bghs.py` | Latitude-band mean BGHS thickness (Figure 3) |
| 3 | `3.build_ml_dataset.py` | Sample all 11 features at BSR positive and negative points |
| 4 | `4.train_classifier.py` | Train and compare five classifiers with 5x5 degree GroupKFold |
| 5 | `5.compare_classifiers.py` | Train all five models, export Table 1 and SHAP values |
| 6 | `6.predict_bsr_probability.py` | Predict global BSR occurrence probability |
| 7 | `7.apply_shallow_water_constraint.py` | Set probability to zero where water depth < 400 m |
| 8 | `8.plot_probability_distribution.py` | Positive vs negative probability distributions (Figure 4b) |
| 9 | `9.plot_shap_beeswarm.py` | SHAP beeswarm summary (Figure 4c) |
| 10 | `10.plot_tp_vs_fn.py` | True positive vs false negative feature comparison (Figure 4d) |
| 11 | `11.train_xgb_regressor.py` | Train XGBoost on BSR residual (observed BSR minus theoretical BGHS) |
| 12 | `12.predict_bsr_depth.py` | Predict global BSR burial depth |
| 13 | `13.estimate_carbon_stock.py` | Volumetric carbon stock under low / medium / high scenarios |
| 14 | `14.plot_carbon_vs_depth.py` | Carbon stock vs BSR depth (Figure 5b) |
| 15 | `15.plot_carbon_comparison.py` | Comparison with published global estimates (Figure 5c) |
| 16 | `16.plot_regional_carbon.py` | Carbon stock across major BSR regions (Figure 5d) |

## Key results

- Theoretical BGHS: 95.0% of ocean cells have a stability zone; mean thickness
  about 433 m, median about 482 m.
- Classifier performance (5x5 degree spatial CV): XGBoost AUC = 0.98, F1 = 0.90.
- BSR high-probability area (P >= 0.5): 3.65% of ocean area; 88.1% of those
  cells have BSR depth between 200 and 500 m.
- Global hydrate carbon stock:
  - Low: 2,410 Gt C (porosity 50%, saturation 1%, gas factor 160)
  - Medium: 5,468 Gt C (porosity 55%, saturation 2%, gas factor 165)
  - High: 17,136 Gt C (porosity 65%, saturation 5%, gas factor 175)
- The low estimate is consistent with recent mainstream low-end estimates
  (1,500-3,000 Gt C).

## Reproducibility notes

- Random seed is fixed at 42 for all models and SHAP sampling.
- Spatial cross-validation uses 5x5 degree blocks (GroupKFold) to prevent
  spatial autocorrelation from inflating accuracy.
- Tree-based models (XGBoost, LightGBM, Random Forest) may show small run-to-run
  variability due to floating-point non-determinism, thread scheduling, and
  differences in library versions or hardware. Overall trends and conclusions
  are stable, and the evaluation protocol is fully reproducible.
