# Global Hydrate Carbon Stock from BSR-Constrained Machine Learning

Code and data for estimating global marine gas hydrate carbon stock using a
physics-constrained machine-learning framework.

## Overview

This repository implements a complete pipeline that:

1. Computes the theoretical base of the gas hydrate stability zone (BGHS)
   from methane hydrate phase equilibrium.
2. Trains XGBoost classifiers on global bottom-simulating reflector (BSR)
   observations to predict BSR occurrence probability.
3. Applies a shallow-water physical constraint to suppress thermodynamically
   impossible predictions.
4. Trains an XGBoost regressor to predict the BSR residual (observed BSR depth
   minus theoretical BGHS) and converts it to absolute BSR burial depth.
5. Estimates global hydrate carbon stock under three parameter scenarios using
   the volumetric method.

The central idea is "physics sets the baseline, machine learning learns the
residual": the phase-equilibrium model provides a first-order physical
constraint, and the ML models capture systematic deviations that the physical
model cannot resolve at global scale.
